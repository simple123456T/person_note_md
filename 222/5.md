## 0. 先说结论：这版计划为什么和上一版不同

上一版最大的问题不是知识点选错，而是学习材料的“入口难度”偏高：

```text
HF 官方文档
        ↓
CS336 / 论文
        ↓
自己理解
        ↓
自己写代码
```

对于已经具备 CV 算法工程经验、但 Transformer/LLM 体系还没有真正建立起来的人，这条路线很容易变成“看懂几个词，但没有形成内部模型”。

本版改成：

```text
中文教程 / 中文笔记
        ↓
配套 Notebook / 源码
        ↓
自己修改代码
        ↓
小实验
        ↓
记录结果
        ↓
再用官方文档 / 论文补原理
```

本月真正的**第一梯队主教材**只有 4 套：

1. [Datawhale / llms-from-scratch-cn](https://github.com/datawhalechina/llms-from-scratch-cn) —— 第一周主线，从零理解 Attention、Transformer、GPT。

4. [Datawhale / llm-algo-leetcode](https://github.com/datawhalechina/llm-algo-leetcode) —— 全月的手撕代码、PyTorch、推理、显存、优化练习场。

辅助教材：

- [LLaMA-Factory](https://github.com/hiyouga/LlamaFactory) —— 真正训练 Qwen3 / LoRA / QLoRA / DPO 的工程入口。
- [transformers-docs-zh](https://github.com/Airmomo/transformers-docs-zh) —— Hugging Face 中文学习笔记 + Notebook + 参数解释。
- [diy-llm](https://github.com/datawhalechina/diy-llm) —— 第二个月继续深入；本月只在遇到难点时查。
- [Start-MLLM](https://github.com/datawhalechina/start-mllm) —— 第二个月进入 VLM 时使用；本月先不展开。

# 3. 学习方式：每天固定使用“5步法”

每天不超过 1 个主教材 + 1 个辅助材料 + 1 个代码任务 + 1 个实验。

## Step 1：先读中文材料

目标不是背。

只回答：

- 它是什么？
- 输入是什么？
- 输出是什么？
- 为什么需要它？
- 它解决什么问题？

## Step 2：立即运行对应代码

不要先把全文看完。

例如今天学 Attention：

```text
看 Attention 解释
↓
打开 Notebook
↓
运行第一格
↓
观察 Tensor Shape
↓
自己修改 batch / seq / head
```

## Step 3：删除代码重新写

至少完成：

```text
原代码运行
→ 改参数运行
→ 删除关键函数
→ 自己补回来
→ 自己从空文件写
```

## Step 4：必须做一个小实验

例如：

- 改 batch size
- 改 seq_len
- 改 num_heads
- 改 LoRA rank
- 改 learning rate
- 改并发
- 改量化方式

## Step 5：脱稿讲 3～5 分钟

回答：

> “如果面试官突然让我解释这个东西，我能不能不用搜索讲出来？”

不能，就不能算学完。

## Day 2｜Scaled Dot-Product Attention

### 主资料

`llms-from-scratch-cn/Codes/ch03/ch03.ipynb`

`multihead-attention.ipynb`

### 辅助资料

Happy-LLM：Transformer 章节中 Attention 部分

https://datawhalechina.github.io/happy-llm/

### 代码任务

自己写：

```python
scores = Q @ K.transpose(-2, -1)
scores = scores / math.sqrt(d_k)
scores = masked_fill(scores)
attn = softmax(scores, dim=-1)
out = attn @ V
```

### 必须真正理解

为什么：

```text
QK^T
```

能表示相似度？

为什么除：

```text
sqrt(d_k)
```

为什么需要 causal mask？

为什么 softmax 放在这里？

### 实验

观察：

- `d_k=8 / 32 / 128`
- 是否 scaling
- 是否 causal mask

比较 attention score 的数值范围。

### 输出

```text
attention.py
attention_notes.md
```

### 考核

脱稿解释：

> 一个 `[B, H, T, D]` 的 Q/K/V 是怎么计算成 Attention Output 的？

# 16. 面试表达模板

以后所有 LLM 技术问题尽量用这个结构回答：

```text
1. 它是什么
2. 为什么需要它
3. 核心原理是什么
4. 输入输出是什么
5. 怎么实现
6. 我的实验是什么
7. 实验结果是什么
8. 遇到问题怎么定位
9. 它的局限是什么
```

例如问：

> 为什么使用 LoRA？

不要回答：

> LoRA 是一种参数高效微调方法。

应该回答到：

```text
全参微调
→ 所有 W 都更新
→ 参数量 / 优化器状态 / 显存成本高

LoRA
→ 冻结 W
→ 学一个低秩增量 BA
→ 大幅减少训练参数
→ 更适合单卡垂域微调

但是
→ rank 过小可能容量不足
→ target modules 影响效果
→ adapter 仍不是“天然免费”
```

最后再接自己的实验结果。

# 21. 最后一句话

本月不要追求：

> “我把多少大模型课程学完了。”

真正应该追求的是：

```text
我能解释
↓
我能写
↓
我能训练
↓
我能评测
↓
我能分析 Badcase
↓
我能优化
↓
我能部署
↓
我能用真实数据证明自己的结论
```

你现在最大的优势并不是“懂多少 LLM 八股”，而是已经有真实 CV 算法和 GPU 推理工程经验。第一月最应该做的是把这部分经验迁移到：

```text
LLM 数据
+
LLM Training
+
LLM Post-Training
+
LLM Evaluation
+
LLM Inference
```

这样形成的能力结构，会比单纯从零学一个“大模型课程”更符合你的转岗目标。
