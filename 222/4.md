# LLM 算法岗 30 天冲刺计划（在职版）

> 背景定位：有 YOLOv5 训练全流程经验（数据/标注/训练/调参/部署），现职大模型部署（vLLM / Milvus）。
> 目标：一个月内建立 LLM 算法体系 + 补上"训练"项目 + 把部署经验算法化，达到中小公司算法/推理算法岗面试水平。
> 节奏：每天约 3 小时（工作日晚 2h + 周末加量），共约 90h。
> 铁律：每天 1h 学、1h 练、1h 整理八股/刷 LeetCode，三线并进，不要连续一周只看视频。

## 第 3 周：训练项目——简历核心（约 30h）

> 目标：产出简历上的"大模型训练"项目，以及面试追问的全部弹药。

- [ ] 用 [LLaMA-Factory](https://github.com/hiyouga/LLaMA-Factory) 对 Qwen2.5-0.5B/1.5B 做后训练：
  - [ ] 自建数据集：收集 → 清洗 → 去重 → 格式化（发挥你 YOLO 数据经验）

  - [ ] 学习率对比（如 1e-4 vs 2e-5）
  - [ ] LoRA rank 对比（8 vs 32 vs 64）
  - [ ] 数据量对比（全量 vs 1/2 vs 1/4）
  - [ ] 每组记录：loss 曲线、显存占用、训练时长、评测得分
- [ ] 评估体系：自建 30~50 条评测题 + badcase 分析文档
- [ ] LeetCode：累计完成 20 题

**本周过关标准**：

- [ ] 项目能扛住 5 层追问：数据怎么来怎么洗 → 超参为什么这么定 → 怎么评估、基线是什么 → badcase 怎么分析 → 资源×10 怎么改

## 避坑清单

1. 不要从读原论文开始，先用视频建立直觉；
2. 不要恋战"从零手写一切"——你 time-boxed，重点在体系与项目；
3. 每个学过的主题必须"讲得出"（录音自测），只看不讲等于没学；
4. 项目实验数据必须当天记录，面试弹药靠平时的笔记；
5. LeetCode 从第 1 天就开始，不要拖到第 4 周。

## 一个月后的投递策略

1. **第一优先**：现公司内部转岗——主动接训练/微调任务；
2. **主攻**：中小公司/创业公司"大模型算法工程师（偏微调/数据/落地）"；
3. **捷径**：推理优化/推理算法岗（vLLM 经验 + 量化/解码算法知识，对口度最高）；
4. **缓攻**：大厂算法岗（本科社招被学历卡概率大，作为 2~3 个月后的目标，走内推）。
