## 附录

### 术语对照表

| 中文 | 英文 | 含义 |
|---|---|---|
| 编码器/解码器 | Encoder / Decoder | 读入源序列 / 生成目标序列 |
| 词嵌入 | Word Embedding | 词 → 稠密向量的查表 |
| 位置编码 | Positional Encoding (PE) | 注入词序信息 |
| 自注意力 | Self-Attention | 序列内 Q/K/V 同源的注意力 |
| 查询/键/值 | Query / Key / Value | 找关系 / 被匹配 / 被加权取用的内容 |
| 缩放点积注意力 | Scaled Dot-Product Attention | softmax(QKᵀ/√d_k)V |
| 多头注意力 | Multi-Head Attention | h 组注意力并行 + 拼接 + 输出投影 |
| 残差连接 | Residual Connection | x + 子层输出，防退化 |
| 层归一化 | Layer Normalization | 对单样本特征维归一化 |
| 前馈网络 | Feed-Forward Network (FFN) | 逐位置两层全连接 |
| 掩码 | Mask（Masked） | 遮住未来位置，保证因果 |
| 交叉注意力 | Cross-Attention | Q 与 K/V 不同源的注意力 |
| 强制教学 | Teacher Forcing | 训练时用标准答案作 Decoder 输入 |
| 自回归 | Autoregressive | 一个词一个词地生成、新词拼回输入 |
