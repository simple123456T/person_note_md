## Step 10 自测清单 + 公式速查

### 10.1 自测清单（能不看笔记讲清楚这 15 条就算过关）

1. 画出 Transformer 整体结构图，标出 Encoder/Decoder、各自的子层和数量；
2. 说出 X、Q、K、V、C 各自的形状和含义；
3. 解释为什么需要位置编码，写出正弦 PE 公式并解释每个符号；
4. 解释"PE(pos+k) 可由 PE(pos) 线性变换得到"；
5. 写出 Self-Attention 公式，并说明每一步的作用（为什么除 √dk、为什么按行 softmax、为什么乘 V）；
6. 用"检索"比喻讲清 Q、K、V 三个角色的分工；
7. 解释 W_Q/W_K/W_V 的行列数为什么必须是 d（单头）或 d×(d/h)（多头）；
8. 解释 Multi-Head 的拼接 + W_O 输出投影，说明它为什么重要；
9. 解释残差连接和 LayerNorm 的作用，说出它们和 ResNet/BatchNorm 的关系与区别；
10. 写出 FFN 公式，说出内层维度和"position-wise"的含义；
11. 解释 Mask 的作用、加在 softmax 前/后、具体怎么实现（-∞）；
12. 解释交叉注意力与自注意力的区别（Q、K、V 来源）与作用；
13. 说出训练和推理时 Decoder 的输入分别是什么、为什么训练能并行；
14. 讲清 decoder-only（GPT）和 encoder-decoder（原论文）在结构上的差别；
15. 用自己的话解释：为什么"上下文信息 + 可并行"让 Transformer 能随规模涌现智能。

### 10.2 核心公式速查表

| 模块 | 公式 |
|---|---|
| 输入表示 | X = 词 Embedding + 位置编码 PE |
| 位置编码 | $PE_{(pos,2i)}=\sin(pos/10000^{2i/d})$，$PE_{(pos,2i+1)}=\cos(pos/10000^{2i/d})$ |
| 线性变换 | Q = XW_Q，K = XW_K，V = XW_V |
| Self-Attention | Attention(Q,K,V) = softmax(QKᵀ/√d_k)·V |
| Multi-Head | MultiHead(X) = Concat(head₁,…,head_h)·W_O，head_i = Attention(XW_i^Q, XW_i^K, XW_i^V) |
| 残差 + 归一化 | LayerNorm(X + Sublayer(X)) |
| Feed Forward | FFN(x) = max(0, xW₁+b₁)W₂+b₂（512→2048→512） |
| Decoder 第一子层 | Masked Self-Attention（softmax 前对"未来"位置加 -∞） |
| Decoder 第二子层 | Cross-Attention：Q 来自 Decoder，K/V 来自 C |
| 输出层 | softmax(Linear(Z)) 预测下一个词 |

### 10.3 形状流转总表

| 阶段 | 操作 | 输入形状 | 输出形状 |
|---|---|---|---|
| 输入 | Embedding + PE | — | n × 512 |
| Encoder 内 | 多头自注意力（每头） | n × 512 | 每头 n × 64 → concat n × 512 |
| Encoder 内 | Add & Norm / FFN | n × 512 | n × 512 |
| Encoder 出 | 6 层堆叠 | n × 512 | C：n × 512 |
| Decoder 第一子层 | Masked 多头自注意力 | n × 512 | n × 512 |
| Decoder 第二子层 | 交叉注意力 | Q：n×512；K/V：m×512（源长 m） | n × 512 |
| Decoder 出 | Linear + Softmax | n × 512 | n × 词表大小 |
