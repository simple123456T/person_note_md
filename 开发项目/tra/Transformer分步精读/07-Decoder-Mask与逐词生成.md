## Step 6 Decoder：逐词生成

### 6.1 Decoder block 与 Encoder block 的三个区别【知乎文】

1. Decoder block 里有**两个** Multi-Head Attention 层；
2. **第一个** Multi-Head Attention 是带 **Masked（掩码）** 操作的自注意力；
3. **第二个** Multi-Head Attention 的 K、V 矩阵用 Encoder 的输出 C 计算，Q 用上一个 Decoder block 的输出计算（即"交叉注意力"，让目标词去源语言里找信息）；
4. 最后多一个 **Softmax 层**算下一个词的概率（第 6.6 节）。

（写 4 条也可以，第 4 条是"输出侧"的区别。）

### 6.2 第一个 MHA 为什么要 Mask：训练时不许偷看未来

翻译是**顺序生成**的：翻译完第 i 个词才能翻译第 i+1 个词，第 i 个词不应该知道它后面的词【知乎文】。

但训练时为了效率要**并行**：把整句正确答案都塞进 Decoder（这叫 **Teacher Forcing**：训练时用"标准答案"当输入，而不是用模型自己上一步的输出），一次算出对所有位置的预测【知乎文】。以"我有一只猫 → I have a cat"为例：

- Decoder 输入序列："`<Begin>` I have a cat"（5 个词）
- 期望输出序列："I have a cat `<end>`"
- 输入第 i 个位置要预测的正是输出第 i 个位置的词（对齐的）

问题来了：如果不做任何处理，预测"I"这个位置时，模型能同时看到 "have a cat"——**答案就在输入里，等于开卷考试**。所以必须加 Mask：**在预测第 i 个词时，把输入里 i 之后位置的词全部遮住**【知乎文】。这样并行训练和"只看过去"的因果性就同时满足了。

【补充】推理（真正翻译）时本来就是一个词一个词生成的，天然看不见未来，理论上不用 Mask；但为了训练/推理行为一致，一般统一带 Mask。

### 6.3 Mask 的实现细节（容易搞混的地方）

用 0 1 2 3 4 5 表示序列 "`<Begin>` I have a cat `<end>`"。训练时输入是前 5 个（0~4），要做的是 5×5 的 Mask 矩阵【知乎文】：

```
            被看的词 j →
         <Begin>  I    have  a    cat
Q <Begin>   1     0     0    0    0     ← 只能看自己
  I         1     1     0    0    0
  have      1     1     1    0    0
  a         1     1     1    1    0
  cat       1     1     1    1    1     ← 最后一个词能看全部
```

- 第 i 行表示"词 i 允许看哪些词"：**只能看自己和更早的词**（上三角是 0）【知乎文】；
- 带 Mask 的 Self-Attention 流程（知乎文五步）：
  1. 输入矩阵 X 与 Mask 矩阵就位；
  2. 照常由 X 算 Q、K、V，算 $QK^{\mathsf T}$；
  3. **在 softmax 之前**把需要遮住的位置变成负无穷（-∞，程序里常用 -1e9），再做 softmax——指数函数把 -∞ 变成 0，于是被遮位置的注意力权重精确为 0【知乎文】。注意顺序：**先 Mask 后 softmax**，不是先 softmax 再乘 0/1；
  4. 与 V 相乘 → 词 i 的输出 Z_i 只包含词 0~i 的信息；
  5. 和 Encoder 一样，多组 Masked Self-Attention 拼成 Multi-Head，再过残差和 LayerNorm。

于是：**句子第 2 行"有"的输出里只包含"我"和"有"的信息，没有后面的"一""个""玩"**（bang 文的说法）——这就是 Decoder 能"一步一步往下推"的原因：**每一步的表示都只凝聚了它前面的语境**，最后一行"玩"的向量就可以用来预测下一个词【bang 文】。

> 程序实现一句话：`masked_scores = scores + mask`，其中 mask 的上三角填 -1e9、其余填 0。因为 softmax 输入统一加一个常数不影响结果，所以"上三角填 -∞、其余填 0"等价于"只保留下三角"。

### 6.4 第二个 MHA：交叉注意力（Cross-Attention）

第二个 Multi-Head Attention 的计算过程和自注意力一模一样，**唯一的区别是 Q、K、V 从哪来**【知乎文】：

- **K、V：来自 Encoder 的编码信息矩阵 C**（C 通过各自的 $W_K、W_V$ 变换得到）——源语言句子的全部信息；
- **Q：来自 Decoder**（上一个 Decoder block 的输出 Z，若是第一个 Decoder block 则用输入矩阵 X）——目标语言当前已生成的部分【知乎文】；
- 不需要 Mask：翻译第 i 个词时可以看源语言句子的**所有**词【知乎文】。

直觉：Decoder 每生成一个新词，都用它去"查询"源语言整句（K/V），找到源语言里和它最对齐/最相关的词，把对应信息取回来融合。这就是**翻译的"对齐"机制**：生成"cat"时，它会重点从"猫"那里取信息。

【bang 文】给的判断标准（通用且好记）：

> **Q 和 K 来自同一个输入 → 自注意力（self-attention）；Q 和 K 来自不同输入 → 交叉注意力（cross-attention）。** 交叉注意力的典型例子是 Stable Diffusion 的 UNet 交叉注意力模块：Q 是图像（隐空间特征），K、V 是文字 prompt 编码，Q 与 K 算的是"文字与图像的注意力关系"，让图像按文字描述生成【bang 文】。
> ⚠️ 评论区有读者指出 bang 原文此处写反了：Stable Diffusion（LDM 论文）里交叉注意力是 **Q 来自图像侧，K/V 来自文本编码侧**（与 bang 文中"Q 是文字、K/V 是图片"相反）。交叉注意力两侧输入 Q 与 K/V 究竟谁是谁，取决于具体模型的设计，本笔记以"Q=图像侧，K/V=文本侧"为 LDM 的准确版本。

### 6.5 Decoder 的输出：Linear + Softmax

Decoder 最后一层之后，要为"下一个词"打分【知乎文】：

1. 取最后一个位置（或每个位置）的输出向量 Z；
2. 过一个 **Linear 层**：把 d 维向量投影到"词表大小"维（比如 3.2 万），得到每个候选词的分数（logits）；
3. **Softmax 变成概率分布**，概率最大的词就是预测的下一个词【知乎文】。

例子（知乎文）：因为有 Mask，第 0 个位置（"`<Begin>`"）的输出 Z0 只含它自己的信息，对它做 softmax 预测出"I"；喂入 "`<Begin>` I"，得到 Z1，预测出"have"……【补充：训练时所有位置同时做这个预测，损失取平均】

### 6.6 训练 vs 推理：一张表看明白

| | 训练（Teacher Forcing） | 推理（自回归生成） |
|---|---|---|
| Decoder 输入 | 整句正确答案："`<Begin>` I have a cat" | 只有自己已经生成的词，从"`<Begin>`"开始 |
| 并行性 | 所有位置一步并行算完（靠 Mask 保证因果） | 每步只能算一个新词，词长 N 要跑 N 步 |
| 预测 | 每个位置同时预测下一个词，和正确答案算交叉熵 | 每步对最后一个位置 softmax 采样一个词（贪心 / top-k / top-p / beam 等），拼进输入继续 |
| 是否用 Mask | 用（关键！） | 天然因果，通常同样加 Mask |

这就是第 1.2 节"Decoder 依次预测"那张图的完整版：**训练时把整句标准答案同时喂进去并行学；上线时没有答案，只能自己一个词一个词地"滚"出来**【知乎文】【补充】。
