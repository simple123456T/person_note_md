## Step 9 常见疑问速查（FAQ）

> 面试/自查高频问题，先自己答再看答案。

**Q1：为什么注意力要除以 √dk？**
防止分数随维度变大而方差增大，进入 softmax 饱和区导致梯度消失；除以 √dk 后分数方差稳定在 1 左右。（第 3.4 节第②步）

**Q2：softmax 是对行还是对列？**
对行——每个 query 词 i 对全部 key 做归一化，每行和 = 1。（第 3.4 节第③步）

**Q3：三个位置/三种注意力分别在哪？**
Encoder：自注意力。Decoder 第一个子层：Masked 自注意力（遮未来）。Decoder 第二个子层：交叉注意力（Q=Decoder，K/V=Encoder 输出 C）。（第 6 节）

**Q4：为什么 Transformer 要位置编码而 RNN 不用？**
RNN 靠循环顺序天然携带位置；Transformer 是对集合做全局运算，交换词序输出只是跟着换位，必须显式注入位置。（第 2.2 节）

**Q5：为什么位置编码用 sin/cos 而不用训练得到的？**
公式法可以外推任意长度，且相对位置 PE(pos+k) 是 PE(pos) 的线性变换，便于模型学习相对关系。（第 2.4 节）

**Q6：Mask 是在 softmax 之前还是之后？**
之前。把未来位置加上 -∞（实现中常为 -1e9），softmax 后这些位置精确为 0。（第 6.3 节）

**Q7：Masked 矩阵里的 0 是直接乘到分数上吗？**
不是。0/1 是示意图；实现是加 -∞，乘 0 会在 softmax 后留下错误的比例关系（实际上 softmax 输入加常数不改变结果，所以加 -∞ 是对的做法）。

**Q8：Add & Norm 里的 Add 加的是什么？为什么能加？**
X + Sublayer(X)，残差连接；因为子层输出与输入维度一致。作用是梯度捷径 + 学增量。（第 5.1 节）

**Q9：LayerNorm 和 BatchNorm 有什么区别？**
LN 对一个样本的所有特征归一化（不依赖 batch）；BN 对一个特征跨 batch 归一化。NLP 用 LN。（第 5.2 节）

**Q10：为什么 Transformer 可以并行训练，而 RNN 不行？**
同一层内各 token 的计算互不依赖（全是矩阵乘 + 逐行 softmax），一次前向同时处理整句；RNN 每步依赖上一步的隐状态，只能串行。（第 0.2 节）

**Q11：多头"多"在哪里？参数变多吗？**
多组并行的 W_Q/W_K/W_V，各自在低维子空间学不同关系，concat + W_O 融合；总参数量与单头一致（d² vs h×(d/h)² + d² 量级相当），计算可并行。（第 4 节）

**Q12：Encoder 的输出 C 在 Decoder 里怎么用？**
作为 K、V 的来源。Decoder 每个词（Q）去查询源语言所有词，取回对齐信息。（第 6.4 节）

**Q13：什么是 Teacher Forcing？**
训练时把"标准答案序列"当作 Decoder 输入，一步并行算所有位置的预测，配合 Mask 保证因果。（第 6.2 节）

**Q14：为什么 W_Q/W_K/W_V 必须是方阵？**
输出维度要等于输入维度才能多层堆叠，且行数必须等于输入维度才能相乘。（第 3.3 节）

**Q15：KV Cache 是什么？（扩展）**
推理自回归时，前面已生成词的 K、V 每步都在重复计算；把它们缓存下来，每步只算新词，能省大量计算。（与本文概念相关的工程优化，面试常问）

**Q16：输入的文字到底是怎么变成"词向量 + 位置向量"的？**
五步流水线：① 分词成 token → ② 查词表得整数 id → ③ 按 id 查可训练的 Embedding 表得**词向量**（E 的第 id 行）→ ④ 按 pos 算 sin/cos（或查可训练位置表）得**位置向量** → ⑤ 逐位相加得 X。全程是查表/公式运算，与前面的词无关，所以整句并行。词向量表在训练中会更新；原论文的 sin/cos 位置向量**没有参数、不参与训练**。（见本节开头的"5 步流水线"与数字示意表）
