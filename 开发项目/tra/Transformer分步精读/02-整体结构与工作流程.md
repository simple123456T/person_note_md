## Step 1 整体结构：先看地图

### 1.1 架构总览

Transformer 由 **Encoder（编码器）** 和 **Decoder（解码器）** 两部分组成，**每部分各 6 个 block**【知乎文】【原论文】。翻译任务里的职责分工：

- **Encoder**：读完整句源语言，产出这句话的"编码信息矩阵" C；
- **Decoder**：一边看已经翻译出来的部分，一边反复"查询"C，逐词生成目标语言。

【补充】6 这个数字来自原论文的 base 配置，可调；现在的大模型（GPT 等）不用 Encoder，Decoder 直接叠 96 层（见第 8 节）。

```
            源语言句子: "我有一只猫"
                    │
           词向量 + 位置编码
                    │
     ┌──────────────▼──────────────┐
     │          Encoder ×6         │
     │   ┌─────────────────────┐   │
     │   │  Multi-Head 自注意力  │   │  ← Q,K,V 都来自本层输入
     │   └──────────┬──────────┘   │
     │              │ 残差 + LayerNorm
     │   ┌──────────▼──────────┐   │
     │   │   Feed Forward(FFN) │   │  ← 两层全连接
     │   └──────────┬──────────┘   │
     │              │ 残差 + LayerNorm
     └──────────────┼──────────────┘
                    │
             编码矩阵 C            ───────────┐
                                            │ (供 Decoder 查询)
     ┌──────────────┼───────────────────────┘
     │          Decoder ×6                    │
     │   ┌─────────────────────┐              │
     │   │ Masked 自注意力(带掩码)│ ← Q,K,V 来自 Decoder 输入；掩码遮住"未来"位置
     │   └──────────┬──────────┘              │
     │              │ 残差 + LayerNorm
     │   ┌──────────▼──────────┐   ┌──────────┘
     │   │ 交叉注意力 Cross-Attn │◄──┘  Q 来自 Decoder
     │   │                    │      K,V 来自 Encoder 的 C
     │   └──────────┬──────────┘
     │              │ 残差 + LayerNorm
     │   ┌──────────▼──────────┐
     │   │      Feed Forward   │
     │   └──────────┬──────────┘
     │              │ 残差 + LayerNorm
     └──────────────┼──────────────┘
                    │
            Linear + Softmax
                    │
        "I have a cat" 逐词的概率分布
```

### 1.2 工作流程三步【知乎文】

以"我有一只猫 → I have a cat"为例：

1. **第一步（构造输入）**：取句子每个单词，得到表示向量 X。X = 单词 Embedding + 位置 Embedding（第 2 节）。
2. **第二步（Encoder 编码）**：把 X 传入 Encoder。X 是 $n\times d$ 矩阵（n = 单词个数，d = 向量维度，论文里 d = 512），**每一行是一个单词**。经过 6 个 block 后，输出句子所有单词的编码信息矩阵 C。**每一个 Encoder block 输出的矩阵形状与输入完全一致**（都是 $n\times d$），这是它能反复堆叠的前提（第 3.3 节会讲为什么必须一致）。
3. **第三步（Decoder 解码）**：把 C 传给 Decoder。Decoder 根据"当前已翻译的词 1~i"预测下一个词 i+1。预测 i+1 时，需要把 i+1 **之后**的词遮住（Mask），否则就"偷看答案"了（第 6.3 节）。

【补充】第 3 步的预测例子（来自知乎文）：输入"`<Begin>`" → 预测出"I"；输入"`<Begin>` I" → 预测出"have"；以此类推，生成结束符"`<end>`"为止。`<Begin>` 和 `<end>` 是两个特殊符号（开始符/结束符）。

### 1.3 贯穿全文的形状约定

后面所有细节里，牢记两件事，就不会迷路：

| 记号 | 含义 | 论文中的尺寸 |
|---|---|---|
| $n$ | 句子长度（词/token 数） | 变长，如 5~100 |
| $d_{model}$ | 词向量/隐藏层维度 | 512 |
| X | 输入矩阵，每行一个词 | $n\times 512$ |
| Q, K, V | 查询/键/值矩阵 | $n\times d_k$ |
| C | Encoder 最终输出 | $n\times 512$ |
