## 对数定义

如果 `aˣ = b`(a > 0 且 a ≠ 1),那么:

**x = logₐ(b)**

读作"以 a 为底 b 的对数",意思是:**a 的多少次方等于 b**。

-   `a` 叫**底数**
-   `b` 叫**真数**(必须 > 0)
-   `x` 叫**对数**

## 举例

-   `log₂(8) = 3`,因为 2³ = 8
-   `log₁₀(1000) = 3`,因为 10³ = 1000
-   `log₅(25) = 2`,因为 5² = 25
-   `log₃(1/9) = -2`,因为 3⁻² = 1/9

## 两个常用特殊底数

-   **常用对数**:`lg(b) = log₁₀(b)`,底数是 10
-   **自然对数**:`ln(b) = logₑ(b)`,底数是 e ≈ 2.71828

## 核心公式(运算性质)

设 M > 0,N > 0:

| 性质 | 公式 |
| --- | --- |
| 乘法 | logₐ(M·N) = logₐM + logₐN |
| 除法 | logₐ(M/N) = logₐM − logₐN |
| 幂 | logₐ(Mᵏ) = k·logₐM |
| 换底公式 | logₐb = log꜀b / log꜀c(常用:logₐb = ln b / ln a) |

几个恒等式:

-   logₐ(1) = 0
-   logₐ(a) = 1
-   a^(logₐb) = b
-   logₐ(M) = logₐ(N) ⟺ M = N

## 简易理解

对数就是**指数的逆运算**:指数问"a 的几次方是 b",对数正好反过来回答这个问题。例如 2³ = 8 与 log₂8 = 3 表达的是同一件事。
