**欧几里得距离就是"两点之间的直线距离"**——就是你在三维空间里拿尺子量的那种距离。它是衡量两个向量（点）差多远最直观的指标，正好对应你 notebook 里说的"词向量越近，语义越相似"。

## 公式

两个向量 $A=(a_1, a_2, ..., a_n)$ 和 $B=(b_1, b_2, ..., b_n)$ 的欧几里得距离：

$$d(A, B) = \sqrt{(a_1-b_1)^2 + (a_2-b_2)^2 + \cdots + (a_n-b_n)^2}$$

通俗解释三步：
1. **对应分量相减**：每个维度上 A 减 B，得到"每个方向差了多远"；
2. **各自平方**：把差都变成正数（也惩罚大的偏差）；
3. **加起来开根号**：合成一条总的直线距离。

其实就是**勾股定理的推广**：二维里是 $\sqrt{(x_1-x_2)^2+(y_1-y_2)^2}$，三维加一项 $(z_1-z_2)^2$，n 维就加 n 项。

## 用你 notebook 里的数据算一遍

三个词向量（三维）：

```
猫  = (0.30, 0.40, 0.25)
狗  = (0.35, 0.45, 0.30)
爱  = (0.80, 0.80, 0.80)
```

**猫 vs 狗**（语义相近，应该离得近）：

$$\sqrt{(0.30-0.35)^2+(0.40-0.45)^2+(0.25-0.30)^2} = \sqrt{0.0025+0.0025+0.0025} = \sqrt{0.0075} ≈ 0.087$$

**猫 vs 爱**（语义差异大，应该离得远）：

$$\sqrt{(0.30-0.80)^2+(0.40-0.80)^2+(0.25-0.80)^2} = \sqrt{0.25+0.16+0.30} = \sqrt{0.71} ≈ 0.84$$

0.087 vs 0.84，**差了近 10 倍**——距离小 = 语义接近，这正是 notebook 那段话想演示的。

## 用代码计算

```python
import numpy as np

cat = np.array([0.30, 0.40, 0.25])
dog = np.array([0.35, 0.45, 0.30])
love = np.array([0.80, 0.80, 0.80])

# 两种写法等价
d1 = np.linalg.norm(cat - dog)            # 最简洁
d2 = np.sqrt(np.sum((cat - dog) ** 2))    # 对照公式手写

print(d1)  # 0.0866
print(d2)  # 0.0866
print(np.linalg.norm(cat - love))         # 0.8426
```

`np.linalg.norm(向量差)` 就是"取向量长度"，也就是距离。

## 一个相关知识点

在词向量/文本领域，除了欧几里得距离，更常用的是**余弦相似度**（量夹角、不看长短）。两者关系：欧几里得距离对"向量的长度"敏感（同样方向、长度差一倍的两个向量距离很大），余弦只关心方向。欧几里得距离**小**= 相似，余弦相似度是**大**= 相似，方向相反。等你学到相似度对比时，这两个通常一起出现。
