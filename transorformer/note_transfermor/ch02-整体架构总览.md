# 第 2 章 整体架构总览

> **本章目标**：先把整张架构图看懂，知道有哪些零件、数据怎么流。
> 具体每个零件怎么算，是后面几章的事。**先建骨架，再填血肉。**

## 2.1 一张图看懂 Transformer

这是论文里的经典结构图（左半是 Encoder，右半是 Decoder）：

                          ┌───────┴───────┐

> 论文原图见 [pdf 第 3 页](https://arxiv.org/abs/1706.03762)。
> 建议把论文那张图打印出来贴在旁边，对照着读本文。

**图里能看出的 6 件事**：

1. 左边 **Encoder**（编码器）负责"读懂"输入句子。
2. 右边 **Decoder**（解码器）负责"写出"目标句子。
3. 两边都是 **N=6 个 Block 堆叠**（图中 ×6）。
4. 每个 Block 里都是 `注意力 → Add & Norm → 前馈网络 → Add & Norm` 这个套路。
5. **唯一的跨模块连接**：Encoder 的输出 $C$ 送给 Decoder 的第二个注意力层。
6. Decoder 的输入输出是**右移一位**的（下面会讲）。

## 2.2 超参数速查表

论文里的 base 模型（本节所有数字都指它）：

| 超参数 | 符号 | 值 | 说明 |
|---|---|---|---|
| 模型维度 | $d_{model}$ | 512 | 每个 token 用 512 维向量表示 |
| 层数 | $N$ | 6 | Encoder 6 层、Decoder 6 层 |
| 注意力头数 | $h$ | 8 | 每个头 64 维 |
| 每头维度 | $d_k = d_v$ | 64 | $= 512/8$ |
| FFN 中间维度 | $d_{ff}$ | 2048 | $= 4 \times 512$ |
| Dropout | $P_{drop}$ | 0.1 | |
| 词表大小 | $V$ | 37000 | 英德 BPE，两种语言共享 |
| 总参数量 | | ≈ 65M | base 模型 |

big 模型：$d_{model}=1024$，$h=16$，$d_{ff}=4096$，参数量 **213M**。

> 对比一下：GPT-3 是 $d_{model}=12288$、$h=96$、$N=96$、上下文 2048、**1750 亿**参数。
> 结构完全一样，只是把数字放大了 20 倍。

## 2.3 数据流：中英翻译走一遍

用 `我有一只猫 → I have a cat` 做例子。

### 第一步：输入表示

```
"我 有 一只 猫"
      ↓ 查词表
[1024, 3351, 882, 2213]          ← token id
      ↓ Embedding 查表
4 个 512 维向量                     ← 词嵌入
      ↓ 加上位置编码
X: (4, 512)                        ← 这就是 Encoder 的输入
```

**关键点**：$X$ 的形状是 `(序列长度, d_model)` = `(4, 512)`。**一行是一个词。**

### 第二步：Encoder 编码

```
X (4, 512)
   ↓ Encoder Block 1
(4, 512)
   ↓ Encoder Block 2
  ...
   ↓ Encoder Block 6
C (4, 512)     ← 编码信息矩阵
```

**每一层的输入输出形状完全一样**，都是 `(4, 512)`。所以才能叠 6 层、60 层、96 层。

那变化的是什么？**是数值的含义**：

- 第 0 层（就是 $X$）：每个词只是一个"孤立的词义向量"。
- 第 6 层（就是 $C$）：每个词的向量已经**融合了全句所有词的信息**，是"语境中的词义"。

举个直观的例子：

```
孤立的 "bank"：[0.2, -0.5, ...]   ← 只知道是"银行"或"河岸"，分不清
经过编码后：
   在 "I went to the bank to deposit money" 里 → 向量偏向"金融机构"
   在 "We sat on the bank of the river"    里 → 向量偏向"河岸"
```

同一个词，**不同上下文得到不同的向量** —— 这就是"上下文相关表示"，也是 Transformer 最核心的能力。

### 第三步：Decoder 逐词生成

这是最容易糊涂的地方，务必看清楚。

Decoder 也是 6 层，输入是**已经生成的译文（右移一位）**：

```
目标译文:   <Begin>  I  have  a  cat  <End>
             ↑
       训练时，Decoder 的输入是：
             <Begin>  I  have  a  cat        (去掉 <End>)
       它要预测的输出是：
             I  have  a  cat  <End>          (去掉 <Begin>)
```

这个"错开一位"的设计叫 **Teacher Forcing**（教师强制），意思是：**不管模型上一步猜得对不对，下一步都喂给它正确的词。**

于是每个位置的任务变成：

```
输入 <Begin>            → 应该输出 "I"
输入 <Begin> I          → 应该输出 "have"
输入 <Begin> I have     → 应该输出 "a"
输入 <Begin> I have a   → 应该输出 "cat"
输入 <Begin> I have a cat → 应该输出 "<End>"
```

**这 5 个任务可以同时训练**（因为答案都已知），这就是训练时可以并行的原因。

但注意，如果什么都不做，当 Decoder 在处理位置 1（`I`）时，它会"看到"后面所有的词 `have a cat`，那就等于抄答案了。

所以要加 **Mask（掩码）**：把每个位置"未来"的信息遮住，只允许看自己和前面的。

```
允许看到的范围（√ = 可见，× = 遮住）：

             <Beg>   I    have   a    cat
   <Beg>      √      ×     ×     ×     ×
   I          √      √     ×     ×     ×
   have       √      √     √     ×     ×
   a          √      √     √     √     ×
   cat        √      √     √     √     √
```

这就是 **Masked Multi-Head Attention**（图里 Decoder 的第一个注意力）。详见 [ch10](ch10-Decoder与掩码机制.md)。

### 第四步：交叉注意力 —— Encoder 和 Decoder 的唯一接口

Decoder 的第二个注意力层叫 **交叉注意力（Cross-Attention）**，它是整个架构里最巧妙的设计：

```
Q  ← 来自 Decoder 自己（"我现在要翻译第 3 个词，我需要什么信息？"）
K  ← 来自 Encoder 的输出 C（"原文第 j 个词的特征是……"）
V  ← 来自 Encoder 的输出 C（"如果决定关注第 j 个词，取回的内容是……"）
```

用自然语言说：

> Decoder 一边写着英文，一边**回头去原文里查**：我现在要写 `cat` 了，原文里哪个词最相关？
> 一查，发现"猫"这个词的注意力最高，于是把"猫"的信息取回来，帮助确定下一个词是 `cat`。

这就解释了为什么翻译时语序可以自由调整 —— Decoder 想看原文哪个位置就看哪个位置，不受顺序限制。

### 第五步：输出概率

最后一层的输出经过一个线性层（投影到词表大小），再 softmax：

```
Decoder 输出 (5, 512)
      ↓ Linear: 512 → 37000
logits (5, 37000)
      ↓ Softmax（对每一行）
概率 (5, 37000)
      ↓
位置 3 的概率分布：{"a": 0.82, "the": 0.11, "one": 0.04, ...}
```

取概率最大的就是预测结果。

## 2.4 三个"形状不变"的关键约定

这三条是 Transformer 能成立的基础，务必记住：

### 约定一：整个过程形状不变

```
Encoder:  (n, 512) → (n, 512) → ... → (n, 512)
                    ↑ 每层都不变

Decoder:  (m, 512) → (m, 512) → ... → (m, 512)
                    ↑ 每层都不变
```

因为每层的输入输出形状相同，才能：

- 叠 N 层
- 用残差连接 $x + f(x)$（两边形状必须一致才能相加）

### 约定二：一行 = 一个 token

```
     特征0  特征1  ...  特征511
词1 [ 0.2   -0.5        0.8  ]
词2 [ 1.3    0.1       -0.2  ]
词3 [ 0.0    0.7        0.4  ]
```

**行与行之间在"形状"上是独立的**。意思是一个词对应的向量，跟其他词没有形状上的耦合。

那词与词的信息在哪交互？**全部在矩阵乘法里**。$QK^T$ 这个操作，本质上就是让所有行两两算内积。

> 这是理解 Transformer 的一个关键洞察：**它的"混合"发生在矩阵乘法中，而不是靠数据结构的传递。**

### 约定三：注意力不改变形状

```
输入 X:  (n, 512)
输出 Z:  (n, 512)

中间过程:
  Q,K,V:  (n, 512) 或 (n, 64)  ← 多头时会变窄
  QK^T:   (n, n)               ← 变宽的方阵，这是"关系矩阵"
  权重:    (n, n)               ← softmax 后
  Z:      (n, 512)              ← 又变回来
```

那个 $(n, n)$ 的方阵，就是"每个词对每个词的注意力"，是 Transformer 的信息枢纽。

## 2.5 参数量估算

学会算参数量，面试常考，也能帮你判断模型大小。

### 单个 Encoder Block

| 组件 | 参数矩阵 | 参数量 |
|---|---|---|
| Multi-Head Attention | $W^Q, W^K, W^V, W^O$ 各 $d \times d$ | $4d^2$ |
| Feed Forward | $W_1: d \times d_{ff}$，$W_2: d_{ff} \times d$ | $2 d \cdot d_{ff} = 8d^2$ |
| LayerNorm ×2 | $2 \times 2d$ | $\approx 0$ |
| **合计** | | $\approx 12d^2$ |

代入 $d = 512$：$12 \times 512^2 = 3{,}145{,}728 \approx 3.15\text{M}$。

**注意 FFN 占了 $8d^2 / 12d^2 = 2/3$** —— 这是很多人没想到的：Transformer 里大部分参数其实在 FFN，不在注意力。

### 单个 Decoder Block

多了第二个注意力层（交叉注意力）：

$$4d^2 \text{(自注意力)} + 4d^2 \text{(交叉注意力)} + 8d^2 \text{(FFN)} = 16d^2 \approx 4.19\text{M}$$

### 整个 base 模型

| 部分 | 计算 | 参数量 |
|---|---|---|
| Encoder 6 层 | $6 \times 12d^2$ | ≈ 18.9M |
| Decoder 6 层 | $6 \times 16d^2$ | ≈ 25.2M |
| 词嵌入（共享） | $37000 \times 512$ | ≈ 18.9M |
| **合计** | | **≈ 63M** |

> 论文报告的是 **65M**，和这里的 63M 差 2M，差异来自词表实际大小和偏置项、LayerNorm 参数的统计口径。**重点是量级和结构比例**，不是精确到个位。

> 论文还有个细节：**两种语言的词嵌入矩阵、以及最后的输出线性层，三者共享同一套权重**。
> 这叫 weight tying，既省参数又能提升效果。所以词嵌入只算一份（详见 [ch11 11.8 节](ch11-输出层与训练推理.md)）。

和论文报告的 65M 对得上 ✓

## 2.6 训练 vs 推理：一张表看清区别

| | 训练 | 推理（生成） |
|---|---|---|
| Decoder 输入 | 完整的目标序列（右移一位），加 mask | 当前已生成的所有词 |
| 并行度 | **全部位置同时算**（一次前向） | **一个一个词算**（串行） |
| 损失/输出 | 每个位置都算交叉熵，求和 | 只取最后一个位置的概率 |
| 是否知道答案 | 知道（Teacher Forcing） | 不知道 |
| 何时停止 | 固定长度 | 生成 `<End>` 或达到最大长度 |
| 关键优化 | 学习率 warmup | KV Cache、Beam Search |

**为什么训练能并行、推理不能并行？**

关键在于：训练时答案已知，所有位置的目标词都可以一次性喂进去，用 mask 保证每个位置只看得到前面的词，一次前向就算出所有位置的预测。

推理时，第 $i+1$ 个词必须先知道第 $i$ 个词是什么，才能作为输入喂进去，所以只能串行。

> 这个"训练并行、推理串行"的特性，是所有自回归模型（GPT 系列）的固有特点。

## 2.7 本章小结

- Transformer = **Encoder（6 层）+ Decoder（6 层）**，每层都是 `注意力 + Add&Norm + FFN + Add&Norm` 的堆叠。
- **形状永远是 (序列长度, d_model)**，这是能叠层的前提。
- **一行 = 一个 token**，token 之间靠矩阵乘法交互。
- Encoder 输出 $C$ 通过**交叉注意力**送给 Decoder，这是两者唯一的连接。
- Decoder 有两个注意力：**带掩码的自注意力** + **交叉注意力**。
- 训练时 **Teacher Forcing + mask** 实现并行；推理时逐词生成。
- 参数量 $\approx 12d^2$ / Encoder 层，$\approx 16d^2$ / Decoder 层，**FFN 占了 2/3**。
