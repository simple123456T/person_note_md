# 第 4 章 Self-Attention 从直觉到公式

> **本章目标**：这是全书最核心的一章。读完后你应该能从零推导出
> $$\text{Attention}(Q,K,V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$
> 并且能解释公式里**每一个符号为什么存在**。

---

## 4.1 先建立直觉：图书馆找书

Self-Attention 里的 Q、K、V 三个字母来自**信息检索**领域。用一个图书馆的类比：

| 符号 | 名称 | 图书馆类比 |
|---|---|---|
| **Q** | Query（查询） | 你手里拿的**搜索词**："我想找关于猫的书" |
| **K** | Key（键） | 每本书书脊上的**标签/索引**："动物"、"历史"、"菜谱" |
| **V** | Value（值） | 书里的**实际内容** |

**检索过程分三步**：

```
第 1 步：拿你的 Query 去和每一本书的 Key 比对
        "猫" vs "动物"   → 相似度 0.8   ✓ 很相关
        "猫" vs "历史"   → 相似度 0.1   ✗
        "猫" vs "菜谱"   → 相似度 0.3

第 2 步：把相似度归一化成权重（加起来等于 1）
        0.8 / (0.8+0.1+0.3) = 0.67
        0.1 / 1.2           = 0.08
        0.3 / 1.2           = 0.25

第 3 步：按权重把书的内容混合起来
        最终结果 = 0.67 × 动物书内容 + 0.08 × 历史书内容 + 0.25 × 菜谱书内容
```

**这就是 Attention 的全部。** 剩下的都是"怎么算相似度"和"怎么归一化"的技术细节。

### 放到句子里

现在把图书馆换成一句话：

```
句子：我 有 一只 猫

处理"猫"这个词时：
    Q = "猫"发出的查询："我该关注谁？"
    K = 每个词（我/有/一只/猫）提供的索引
    V = 每个词（我/有/一只/猫）提供的内容

    注意力权重：[0.05, 0.05, 0.20, 0.70]
                          ↑            ↑
                      "一只"有点关系   "猫"最相关

    新表示 = 0.05×V(我) + 0.05×V(有) + 0.20×V(一只) + 0.70×V(猫)
```

于是"猫"这个词的新向量里，**融合了全句的信息，但以自己为主**。

## 4.2 从"加权平均"形式化

抽象一下。对于序列中的第 $i$ 个位置，我们要算它的新表示 $z_i$：

$$z_i = \sum_{j=1}^{n} \alpha_{ij} \, v_j$$

其中：

- $v_j$ 是第 $j$ 个位置的 Value 向量
- $\alpha_{ij}$ 是第 $i$ 个位置对第 $j$ 个位置的注意力权重
- 约束：$\sum_j \alpha_{ij} = 1$，且 $\alpha_{ij} \ge 0$

**这就是加权平均。** 现在的问题只剩两个：

1. $\alpha_{ij}$ 怎么算？
2. $v_j$ 从哪来？

---

## 4.3 第一步：把 X 投影成 Q、K、V

### 为什么不能直接用 X？

最朴素的想法：直接用输入 $X$ 当 Q、K、V。

但这样做有个问题：**"我该被谁关注"和"我能提供什么信息"是两件不同的事，用同一个向量表示会很勉强。**

举个例子：`苹果` 这个词，当它出现在 "我吃苹果" 里作为**宾语**时，它需要向"吃"发出很强的查询信号；当它出现在 "苹果公司发布了新手机" 里作为**主语**时，它需要发出的查询信号完全不同。

**同一个词，在不同的角色下，需要不同的表示。** 所以给每个角色配一个专属的投影矩阵，让模型自己去学。

### 计算方式

$$Q = X W^Q, \qquad K = X W^K, \qquad V = X W^V$$

其中：

- $X \in \mathbb{R}^{n \times d_{model}}$（$n$ 个词，每个 $d$ 维）
- $W^Q, W^K, W^V \in \mathbb{R}^{d_{model} \times d_k}$（**可训练参数**）
- $Q, K, V \in \mathbb{R}^{n \times d_k}$

**形状追踪**（这是最需要记住的）：

```
        X          W^Q          Q
   (n, d_model)  (d_model, d_k)  →  (n, d_k)
   (4, 512)      (512, 512)         (4, 512)      ← 单头时 d_k = d_model
   (4, 512)      (512, 64)          (4, 64)       ← 多头时 d_k = d_model/h
```

**关键理解**：$Q$、$K$、$V$ 的**每一行仍然是一个 token**，只是换了一套坐标表示。

> 由矩阵乘法性质：$Q$ 的第一行只由 $X$ 的第一行和 $W^Q$ 算出来，**与其他行无关**。
> 也就是说，投影这一步是**逐 token 独立**的，token 之间的信息还没开始混合。

### 关于 $W$ 矩阵的行列数（bang 的讲法）

bang 的文章用了一个很实用的角度来解释为什么 $W$ 是方阵：

> - **行数**必须等于输入词向量的维度（这里是 9），因为要和 $X$ 相乘，维度得对得上。
> - **列数**也必须等于词向量维度，因为 Attention 模块的**输入和输出维度要一致**，才能一层层叠起来；由矩阵相乘的特性，输出维度 = 列数，所以列数也是 9。

一句话：**$W$ 是 $d_{model} \times d_{model}$，是为了保证"进去多少维，出来还是多少维"。**

（多头的情况下，单个头的 $W$ 是 $d_{model} \times d_k$，拼接回来再乘 $W^O$ 还原成 $d_{model}$。见 [ch06](ch06-Multi-Head-Attention.md)。）

## 4.4 第二步：用 Q 和 K 算相似度

现在要算"第 $i$ 个 query 和第 $j$ 个 key 有多相关"。

### 为什么用内积（点积）？

两个向量的**内积**衡量它们的**相似度**：

$$q \cdot k = \sum_{t=1}^{d_k} q_t k_t = |q| \, |k| \cos\theta$$

$\theta$ 是两个向量的夹角：

```
     q·k > 0，夹角小   → 方向一致，很相似 ✔
     q·k = 0，垂直      → 完全无关
     q·k < 0，夹角大   → 方向相反，负相关 ✗
```

**为什么选内积而不是余弦相似度或其他？**

1. **便宜**：内积只需要乘加，是矩阵乘法的基本单元，GPU 最擅长这个。
2. **可微**：对 $q$ 和 $k$ 都是线性的，梯度好算。
3. **表达力够**：$W^Q$、$W^K$ 是可学的，模型可以自己学会把向量调整到合适的长度和方向。归一化那一步（余弦相似度）反而限制了表达力。

### 一次算完所有对：$QK^T$

不需要写双重循环。把所有 query 堆成矩阵 $Q \in \mathbb{R}^{n\times d_k}$，所有 key 堆成 $K \in \mathbb{R}^{n\times d_k}$：

$$S = QK^T \in \mathbb{R}^{n \times n}$$

**为什么是 $K^T$？** 因为矩阵乘法的定义要求"左矩阵的列数 = 右矩阵的行数"，而且我们想要的是 $S_{ij} = q_i \cdot k_j$：

```
Q (n, d_k)  @  K^T (d_k, n)  =  S (n, n)
                                 ↑
                     第 i 行第 j 列 = q_i · k_j
```

**$S$ 的直观含义**：

```
        k_1     k_2     k_3     k_4      k_5
        我      有     一只     猫      玩
q_1 我 [ 1.2     0.3    0.5     0.8     0.4 ]
q_2 有 [ 0.3     1.5    0.2     0.6     0.9 ]
q_3一只[ 0.5     0.2    1.8     1.1     0.3 ]
q_4 猫 [ 0.8     0.6    1.1     2.0     0.7 ]
q_5 玩 [ 0.4     0.9    0.3     0.7     1.3 ]
```

- **第 $i$ 行** = 第 $i$ 个词对其他所有词（包括自己）的"关系强度"
- **对角线** = 词和自己的相似度
- 这是**两两可重复排列组合**，5 个词得到 $5\times5$ 矩阵（bang 原文）

## 4.5 第三步：为什么要除以 $\sqrt{d_k}$

$$S' = \frac{QK^T}{\sqrt{d_k}}$$

这个 $\sqrt{d_k}$ 是最容易被忽略、但面试最爱问的细节。

### 问题：内积会随维度增长

假设 $q$ 和 $k$ 的每个分量都是**独立的随机变量**，均值 0、方差 1。那么内积：

$$q \cdot k = \sum_{t=1}^{d_k} q_t k_t$$

的期望是：

$$\mathbb{E}[q \cdot k] = \sum_{t=1}^{d_k} \mathbb{E}[q_t]\mathbb{E}[k_t] = 0$$

方差是（因为各项独立）：

$$\text{Var}(q \cdot k) = \sum_{t=1}^{d_k} \text{Var}(q_t k_t) = \sum_{t=1}^{d_k} 1 = d_k$$

所以**标准差是 $\sqrt{d_k}$**。

```
d_k = 64（论文里每个头的维度）：
    内积的标准差 = √64 = 8

d_k = 512（如果不分头）：
    内积的标准差 = √512 ≈ 22.6
```

**维度越高，内积的数值越容易变得很大。**

### 后果：softmax 会饱和，梯度消失

Softmax 对输入的大小极其敏感。看对比（假设四个候选分数）：

| 输入 | softmax 输出 | 现象 |
|---|---|---|
| `[8, 0, 0, 0]` | `[0.999, 0.0003, 0.0003, 0.0003]` | **几乎变成 one-hot** |
| `[1, 0, 0, 0]` | `[0.475, 0.175, 0.175, 0.175]` | 分散、平滑 |
| `[16, 0]` | `[1.0, 0.0]` | 完全饱和 |
| `[2, 0]` | `[0.881, 0.119]` | 仍有梯度 |

**softmax 一旦饱和（输出接近 0 或 1），梯度就接近于 0**，因为 softmax 的导数在极端处趋于 0。

梯度为 0 意味着：**这个位置学不到任何东西**。而且这不是偶发情况 —— $d_k=64$ 时内积标准差就是 8，$d_k$ 越大越严重。

### 解决：除以 $\sqrt{d_k}$ 把方差拉回 1

$$\text{Var}\left(\frac{q\cdot k}{\sqrt{d_k}}\right) = \frac{d_k}{d_k} = 1$$

**让点积的方差与 $d_k$ 无关，恒定为 1。** 这样无论每个头是 64 维还是 128 维，softmax 都工作在"不饱和"的舒适区。

### 更直观的类比

想象你在给一群学生打分：

```
不打分归一化：题目多（维度高）→ 总分动辄几百分 → 排序极端，第一名遥遥领先
除以 √题数：  不管多少题，折算成"平均每题水平" → 差距合理，不会碾压
```

### 一个常见的误区

❌ **"除以 $\sqrt{d_k}$ 是为了防止数值溢出（overflow）。"**

不完全对。$d_k=512$ 时内积也就几十，远不到 float 溢出的程度。真正的问题是**softmax 的梯度饱和**，是训练动力学问题，不是数值精度问题。

> **补充**：论文作者在脚注里说，他们怀疑 $d_k$ 更大时点积绝对值变大导致 softmax 梯度消失，所以做了这个缩放。后来的研究（如 "Attention Is All You Need? A Survey" 之类）确实验证了这个猜想。

## 4.6 第四步：Softmax 归一化

$$A = \text{softmax}(S')$$

**关键：softmax 是"按行"做的。**

$$\alpha_{ij} = \frac{\exp(S'_{ij})}{\sum_{j'=1}^{n} \exp(S'_{ij'})}$$

```
        k_1     k_2     k_3              k_1     k_2     k_3
行1  [  1.2     0.3    0.5 ]   →   [   0.49    0.22    0.29 ]  和 = 1.0
行2  [  0.3     1.5    0.2 ]   →   [   0.24    0.61    0.15 ]  和 = 1.0
行3  [  0.5     0.2    1.8 ]   →   [   0.20    0.16    0.64 ]  和 = 1.0
       └──── 每一行独立做 softmax ────┘
```

**为什么按行？** 因为每一行代表"第 $i$ 个词对所有词的注意力分布"，它必须是一个**概率分布**（和为 1），才能做加权平均。

**第 $i$ 行的含义**（bang 原文）：

> 第 $i$ 行数据表示第 $i$ 个单词与其他单词的关系，归一化后数值可理解为**从全文范围看每个单词对第 $i$ 个单词的重要程度比例**。

注意"对第 $i$ 个单词"这个方向：**是别人对"我"的重要程度，不是"我"对别人的。** 方向别搞反了。

**softmax 的两个好性质**：

1. **非负**：$\alpha_{ij} > 0$，所以是"加权"不是"加权减"。
2. **可放大差距**：指数函数让大分数更突出。这就是"注意力"这个名字的由来 —— 分数高的地方会被**聚焦**。

> **易错点**：如果某一行全部是 $-\infty$（全被 mask 掉了），softmax 会变成 $0/0 = \text{NaN}$。
> 所以实现时用 `-1e9` 而不是 `-inf`。详见 [ch10](ch10-Decoder与掩码机制.md)。

## 4.7 第五步：用权重去取 Value

$$Z = A V$$

形状追踪：

```
   A         V          Z
 (n, n)  @ (n, d_v) = (n, d_v)

 第 i 行：z_i = Σ_j α_ij · v_j
```

**展开看第 $i$ 行**（这是 bang 文章里单独拆解的那一步）：

$$z_i = \alpha_{i1} v_1 + \alpha_{i2} v_2 + \cdots + \alpha_{in} v_n$$

举例，处理"我"这个词：

```
z_我 = 0.05 × v_我 + 0.05 × v_有 + 0.10 × v_一 + 0.70 × v_猫 + 0.10 × v_玩
        └────────────────────────────────────────────────────────────┘
                          加权求和
```

bang 的原文：

> 例如「我」与「一」的权重为 0.1，则「一」的向量对最终「我」的向量结果影响很小，若为 0 则无影响。

**这就是 Self-Attention 的输出。**

## 4.8 完整公式与逐项注解

$$\boxed{\text{Attention}(Q,K,V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V}$$

| 步骤 | 运算 | 形状变化 | 作用 |
|---|---|---|---|
| 1 | $Q = XW^Q,\ K=XW^K,\ V=XW^V$ | $(n,d)\to(n,d_k)$ | 把输入投影成三种角色 |
| 2 | $S = QK^T$ | $(n,d_k)\times(d_k,n)\to(n,n)$ | 算两两相似度 |
| 3 | $S' = S/\sqrt{d_k}$ | $(n,n)$ 不变 | 防止 softmax 饱和 |
| 4 | $A = \text{softmax}(S')$ | $(n,n)$ 不变 | 每行归一化成概率 |
| 5 | $Z = AV$ | $(n,n)\times(n,d_v)\to(n,d_v)$ | 加权求和取信息 |

**一句话总结每一行的物理意义**：

```
Z 的第 i 行 = 全句所有词 Value 的加权平均，
             权重由"第 i 个词的 Query"和"每个词的 Key"的相似度决定。
```

**一句话总结整个模块**：

> **Query 提问，Key 应答，Value 交货。**

## 4.9 一个能心算的极简例子

用 2 个 token、$d_{model}=2$、单头来走一遍。为了让数字干净，**故意取 $W^Q=W^K=W^V=I$（单位矩阵）**：

```
X = [ 1  0 ]      词A
    [ 0  1 ]      词B

因为 W 都是单位矩阵，所以 Q = K = V = X
```

### 第 1 步：算相似度矩阵

$$S = QK^T = \begin{bmatrix} 1 & 0 \\ 0 & 1 \end{bmatrix}\begin{bmatrix} 1 & 0 \\ 0 & 1 \end{bmatrix}^T = \begin{bmatrix} 1 & 0 \\ 0 & 1 \end{bmatrix}$$

**解读**：A 和自己相似度 1，A 和 B 相似度 0（正交，完全无关）。B 同理。

### 第 2 步：缩放

$d_k = 2$，$\sqrt{d_k} = 1.4142$：

$$S' = \begin{bmatrix} 1/1.4142 & 0 \\ 0 & 1/1.4142 \end{bmatrix} = \begin{bmatrix} 0.7071 & 0 \\ 0 & 0.7071 \end{bmatrix}$$

### 第 3 步：按行 softmax

第一行：$\text{softmax}([0.7071, 0])$

$$= \left[\frac{e^{0.7071}}{e^{0.7071}+e^{0}}, \frac{e^{0}}{e^{0.7071}+e^{0}}\right] = \left[\frac{2.0281}{3.0281}, \frac{1}{3.0281}\right] = [0.6698,\ 0.3302]$$

$$A = \begin{bmatrix} 0.6698 & 0.3302 \\ 0.3302 & 0.6698 \end{bmatrix}$$

**解读**：A 关注自己 67%，关注 B 33%。虽然 A 和 B 的内积是 0（无关），softmax 也不会给出 0 —— 因为它必须把概率质量分配出去。

### 第 4 步：加权求和

$$Z = AV = \begin{bmatrix} 0.6698 & 0.3302 \\ 0.3302 & 0.6698 \end{bmatrix}\begin{bmatrix} 1 & 0 \\ 0 & 1 \end{bmatrix} = \begin{bmatrix} 0.6698 & 0.3302 \\ 0.3302 & 0.6698 \end{bmatrix}$$

**结果解读**：

- A 的新向量 `[0.6698, 0.3302]`：以自己为主，混进了一点 B。
- B 的新向量 `[0.3302, 0.6698]`：以自己为主，混进了一点 A。
- **两个词都完成了信息交互**，各自的新表示都包含了对方。

这就是 Self-Attention 的最小完整例子。真实模型只是把 $n$ 从 2 变成几百，$d_k$ 从 2 变成 64，加上可学的 $W$ 矩阵而已。

> 更完整的例子（3 个 token、多头、残差、FFN）见 [ch12 完整数值演练](ch12-完整数值演练.md)，
> 那些数字是用 `code/tiny_forward_numpy.py` 真实跑出来的。

## 4.10 为什么叫 "Self" Attention

"Self" 指的是：**Q、K、V 全部来自同一个输入 $X$**。

$$Q = XW^Q,\quad K = XW^K,\quad V = XW^V \qquad \text{← 都是 X，所以是 Self-Attention}$$

如果 Q 来自一个序列，K/V 来自另一个序列，就叫**交叉注意力（Cross-Attention）**：

$$Q = X_{\text{dec}}W^Q,\quad K = X_{\text{enc}}W^K,\quad V = X_{\text{enc}}W^V$$

Decoder 的第二个注意力层就是这种。详见 [ch10](ch10-Decoder与掩码机制.md)。

## 4.11 复杂度分析

| 操作 | 计算量 | 说明 |
|---|---|---|
| $Q=XW^Q$ 等 | $O(n \cdot d^2)$ | 与序列长度线性 |
| $QK^T$ | $O(n^2 \cdot d_k)$ | **与序列长度平方相关** ⚠️ |
| $AV$ | $O(n^2 \cdot d_v)$ | 同上 |

**$O(n^2)$ 是 Transformer 最大的痛点**：

```
序列长度 512  → 相似度矩阵 512×512   = 26 万个数
序列长度 2048 → 相似度矩阵 2048×2048 = 420 万个数    （长度×4，矩阵×16）
序列长度 128K → 相似度矩阵 128K×128K = 164 亿个数    （根本存不下）
```

这就是"上下文长度"成为大模型核心竞争指标的原因，也是 FlashAttention、稀疏注意力、线性注意力等一系列研究要解决的问题。

> 对比：RNN 是 $O(n \cdot d^2)$（每步都要做 $d\times d$ 的矩阵乘），与 $n$ 线性。
> 所以 Transformer 在**短序列**上比 RNN 更省，在**长序列**上比 RNN 更贵。
> 但 Transformer 能并行，这才是决定性优势。

## 4.12 本章小结

- Self-Attention = **用 Q 和 K 算相似度，softmax 归一化，再拿权重去加权平均 V**。
- 三个 $W$ 矩阵是**可训练参数**，让同一个词在不同角色下有不同的表示。
- 除以 $\sqrt{d_k}$ 是为了**把点积的方差控制住**，避免 softmax 饱和导致梯度消失。
- softmax **按行**做，让每一行成为概率分布。
- 输出的每一行 = 全句 Value 的加权平均，**融合了上下文**。
- 形状：$(n,d) \to (n,d_k) \to (n,n) \to (n,d_v)$，**进出一致**（配合 $W^O$）。
- 复杂度 $O(n^2 d)$，**关于序列长度是平方的**。
